# Shadow-Bees 后端架构文档

## 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        前端 (React)                          │
└────────────────────────┬────────────────────────────────────┘
                         │ HTTP
┌────────────────────────▼────────────────────────────────────┐
│                    Nginx (反向代理)                          │
└────────────────────────┬────────────────────────────────────┘
                         │
┌────────────────────────▼────────────────────────────────────┐
│              Java Spring Boot 微服务                        │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐       │
│  │ Hotel    │ │ Order    │ │ Pricing  │ │ Content  │       │
│  │ Service  │ │ Service  │ │ Service  │ │ Service  │       │
│  └────┬─────┘ └────┬─────┘ └────┬─────┘ └────┬─────┘       │
└───────┼────────────┼────────────┼────────────┼──────────────┘
        │            │            │            │
        └────────────┴──────┬─────┴────────────┘
                            │
┌───────────────────────────▼────────────────────────────────┐
│              数据层 / 中间件                                 │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐       │
│  │PostgreSQL│ │  Redis   │ │ RabbitMQ │ │   ES     │       │
│  │ 主数据库  │ │  缓存    │ │ 消息队列  │ │ 日志检索 │       │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘       │
└────────────────────────────────────────────────────────────┘

外部API:
- PMS: 绿云、中软
- OTA: 携程、美团、飞猪
- 事件: 大麦、12306、高德、天气
- LLM: OpenAI、百度文心
```

## 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| 框架 | Spring Boot 3.2 | 核心框架 |
| 数据访问 | Spring Data JPA | 数据库操作 |
| 缓存 | Spring Data Redis | 热点数据缓存 |
| 消息队列 | Spring AMQP | 异步任务处理 |
| 熔断限流 | Resilience4j | 外部API保护 |
| HTTP客户端 | WebFlux | 非阻塞HTTP调用 |
| 数据库 | PostgreSQL 15 | 主存储 |
| 缓存 | Redis 7 | 缓存/会话/限流 |
| 消息队列 | RabbitMQ 3 | 任务队列 |
| 搜索 | Elasticsearch 8 | 日志检索 |

## 外部API接入设计

### 1. 统一抽象层
```java
AbstractExternalClient
├── PMSClient      // PMS系统
├── OTAClient      // OTA平台
├── EventClient    // 事件API
└── LLMClient      // 大模型
```

### 2. 熔断限流策略
| API | 熔断阈值 | 限流策略 |
|-----|---------|---------|
| PMS | 50%错误率 | 10QPS |
| OTA携程 | 50%错误率 | 100/小时 |
| OTA美团 | 50%错误率 | 100/小时 |
| 大模型 | 50%错误率 | 20/分钟 |

### 3. 缓存策略
| 数据类型 | 缓存时间 | 说明 |
|---------|---------|------|
| PMS房态 | 5分钟 | 实时性要求不高 |
| OTA价格 | 10分钟 | 节省API调用成本 |
| 大模型结果 | 30分钟 | 相同输入复用 |
| 事件数据 | 1小时 | 减少API调用 |

## 消息队列设计

### 队列列表
```
exchange: pricing.exchange
├── pricing.analysis     # 定价分析任务
└── pricing.update       # 价格更新任务

exchange: ota.exchange
├── ota.scrape          # OTA价格抓取
└── ota.price.update    # 竞品价格更新

exchange: llm.exchange
├── llm.pricing         # 大模型定价分析
└── llm.content         # 大模型文案生成

exchange: order.exchange
├── order.create        # 订单创建
└── order.status.update # 状态更新

exchange: dlx.exchange  # 死信队列
└── dlx.queue          # 失败消息处理
```

## 数据库设计

见 `sql/001_schema.sql`

核心表:
- hotels: 酒店基础信息
- room_types: 房型配置
- price_calendar: 价格日历（核心）
- orders: 订单数据
- competitor_prices: 竞品价格
- external_events: 外部事件缓存
- llm_logs: 大模型调用日志
