## 自定义快捷键

### 打开快捷键设置

1. 进入**系统设置**
2. 点击左侧菜单的**快捷键**选项
3. 或使用命令面板搜索"快捷键"

### 修改快捷键

1. 在快捷键列表中找到要修改的功能
2. 点击当前的快捷键显示（蓝色按钮）
3. 按下新的快捷键组合
4. 点击 ✓ 保存，或点击 ✕ 取消

### 支持的快捷键格式

- **单键**: `a`, `b`, `1`, `2`
- **组合键**: `Ctrl+A`, `Ctrl+Shift+P`
- **功能键**: `F1`, `F2`, `Escape`, `Enter`
- **方向键**: `ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`

### 禁用快捷键

点击快捷键右侧的**眼睛图标**可以禁用/启用该快捷键。

### 恢复默认

点击右上角的**重置全部**按钮可以恢复所有快捷键为默认设置。

## 快捷键冲突处理

### 什么是快捷键冲突

当两个功能设置了相同的快捷键时，会发生冲突。

### 冲突提示

设置快捷键时，如果检测到冲突，系统会显示红色提示：

> ⚠️ 快捷键冲突：该快捷键已被其他功能占用

### 解决冲突

1. 选择一个不同的快捷键组合
2. 先禁用另一个占用该快捷键的功能
3. 重置为默认设置

### 浏览器默认快捷键

以下浏览器快捷键无法被覆盖：

| 快捷键 | 浏览器功能 |
|--------|-----------|
| `Ctrl + T` | 新建标签页 |
| `Ctrl + W` | 关闭标签页 |
| `Ctrl + N` | 新建窗口 |
| `Ctrl + Shift + T` | 恢复关闭的标签页 |

## 常见问题

### Q: 快捷键不生效怎么办？

**A:** 请检查以下几点：

1. 确保**快捷键开关**已打开（系统设置 → 快捷键 → 右上角开关）
2. 检查当前焦点是否在输入框中（输入框内快捷键不生效）
3. 刷新页面后重试
4. 检查是否有浏览器插件占用快捷键

### Q: 如何记住这么多快捷键？

**A:** 

1. 先记住主导航的 `Ctrl + 数字`（1-8）
2. 记住通用的 `Ctrl + K`（命令面板）和 `Ctrl + /`（帮助）
3. 其他快捷键可以按需使用，经常使用自然会记住
4. 随时按 `Ctrl + /` 查看帮助

### Q: 为什么所有快捷键都需要 Ctrl 键？

**A:** 

这是为了避免**误触**。如果不加 Ctrl 修饰：

- 在输入框中输入文字时会误触发
- 与其他应用的快捷键冲突
- 新手用户容易意外触发不熟悉的操作

使用 `Ctrl + 键` 是业界通用的快捷键设计模式（如 VS Code、Figma 等）。

### Q: 可以在 Mac 上使用 Cmd 键吗？

**A:** 

目前系统统一使用 `Ctrl` 键，无论是 Windows 还是 Mac。这是为了：

1. 跨平台一致性
2. 避免与 macOS 系统快捷键冲突
3. 简化文档说明

未来版本可能会支持 Cmd 键作为替代方案。

### Q: 如何导出快捷键配置？

**A:** 

快捷键配置自动保存在浏览器本地存储中。如需备份：

```javascript
// 在浏览器控制台执行
localStorage.getItem('sb-shortcut-config-v2');
```

### Q: 快捷键设置会影响其他用户吗？

**A:** 

不会。快捷键配置保存在**浏览器本地**，仅对当前设备生效。每个用户、每台设备都可以有自己的快捷键设置。

## 快捷键设计原则

本项目快捷键设计遵循以下原则：

1. **一致性**: 相同功能在三端使用相似快捷键
2. **可发现性**: 命令面板和帮助系统让功能易于发现
3. **防误触**: 所有快捷键都需要 Ctrl 修饰键
4. **可定制**: 支持自定义快捷键，适应不同用户习惯
5. **渐进式**: 记住核心快捷键即可，高级快捷键按需使用
