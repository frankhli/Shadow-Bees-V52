# Shadow-Bees 企业版 V52 产品需求文档 (PRD)

## 一、文档概述

### 1.1 文档信息
| 项目 | 内容 |
|------|------|
| 产品名称 | Shadow-Bees 企业版 (华美会定制版) |
| 版本号 | V52 |
| 目标用户 | 华美会集团运营人员、酒店店长 |
| 核心定位 | 集团级AI智能代运营平台 |
| 交付形式 | iframe嵌入华美会PMS系统 |

### 1.2 术语表
| 术语 | 说明 |
|------|------|
| 管理端 | Shadow-Bees后端大脑，负责AI训练、数据仓库 |
| 企业端 | 本文档所述系统，华美会操作界面 |
| PMS | Property Management System，酒店管理系统 |
| 非标渠道 | 闲鱼、小红书、微信等私域渠道 |
| RAG | Retrieval-Augmented Generation，检索增强生成 |

### 2.2 数据流向

**上行数据流（企业端 → 管理端）**
```
内容生成 → 发布 → 效果数据 ───────────────────────────────────────────────▶ 内容库
定价操作 → 价格数据 → 订单转化 ───────────────────────────────────────────▶ 价格知识库
客服对话 → 满意度评分 → 人工介入 ─────────────────────────────────────────▶ 客服知识库
订单数据 → 用户行为 → 支付记录 ───────────────────────────────────────────▶ 交易数据仓库
账号操作 → 登录日志 → 风控事件 ───────────────────────────────────────────▶ 账号图谱
```

**下行配置流（管理端 → 企业端）**
```
AI模型更新 ───────────────────────────────────────────────────────────────▶ 模型版本下发
算法参数调优 ─────────────────────────────────────────────────────────────▶ 应用新参数
内容模板更新 ─────────────────────────────────────────────────────────────▶ 模板库更新
客服话术升级 ─────────────────────────────────────────────────────────────▶ 知识库同步
风控规则更新 ─────────────────────────────────────────────────────────────▶ 规则引擎更新
```

| 优先级 | 策略 | 说明 |
|--------|------|------|
| P0 | 完整Mock | 所有功能先用Mock实现，保证可用性 |
| P1 | 配置开关 | 通过`mockManager.ts`控制Mock开关 |
| P2 | 渐进替换 | 逐个API替换为真实接口 |
| P3 | 降级方案 | 真实API失败时自动降级到Mock |

**Mock控制命令（浏览器控制台）**
```javascript
mockControl.enable()      // 启用Mock
mockControl.disable()     // 禁用Mock（使用真实API）
mockControl.setDelay(500) // 设置模拟延迟
mockControl.status()      // 查看当前状态
```
