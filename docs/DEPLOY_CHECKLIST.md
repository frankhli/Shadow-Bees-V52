## 上线流程

### 步骤1: 预发布环境验证
```bash
# 1. 部署到预发布环境
./deploy.sh staging

# 2. 跑通核心业务流程
- 酒店切换
- 订单创建
- 价格更新
- 内容生成
```

### 步骤2: 数据库迁移
```bash
# 1. 备份生产数据库
pg_dump shadowbees > backup_$(date +%Y%m%d).sql

# 2. 执行迁移脚本
flyway migrate
```

### 步骤3: 应用部署
```bash
# 1. 停止旧版本
docker-compose down

# 2. 拉取新版本
git pull origin main

# 3. 构建新版本
docker-compose build

# 4. 启动新版本
docker-compose up -d

# 5. 健康检查
curl https://api.shadowbees.com/actuator/health
```

### 步骤4: 验证
- [ ] 首页能正常访问
- [ ] 登录功能正常
- [ ] 核心业务流程正常
- [ ] 监控数据正常上报

### 步骤5: 观察期（2小时）
- [ ] 错误率 < 0.1%
- [ ] 平均响应时间 < 500ms
- [ ] 无异常告警

## 回滚流程

如果上线后出现问题：

```bash
# 1. 停止新版本
docker-compose down

# 2. 回滚代码
git reset --hard HEAD~1

# 3. 回滚数据库（如需要）
psql shadowbees < backup_20240101.sql

# 4. 启动旧版本
docker-compose up -d
```
