# SaaS运营后台架构设计

## 系统关联方案

### 1. 数据模型关联

```
┌─────────────────────────────────────────────────────────────┐
│                    SaaS 运营后台                             │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │   Customer   │  │  HotelData   │  │   Tenant     │      │
│  │  (客户)      │  │  (酒店数据)   │  │  (租户)      │      │
│  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘      │
│         │                 │                 │               │
│         └─────────────────┼─────────────────┘               │
│                           │                                 │
│                    tenantId ↔ hotelId                       │
└───────────────────────────┼─────────────────────────────────┘
                            │ API / 数据同步
┌───────────────────────────┼─────────────────────────────────┐
│                    酒店端系统                                │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │    Hotel     │  │   Pricing    │  │  Inventory   │      │
│  │  (酒店配置)   │  │   (定价)     │  │   (库存)     │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
│                                                             │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │   Content    │  │  Transaction │  │ Competitor   │      │
│  │  (内容投放)   │  │   (交易)     │  │   (竞品)     │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
└─────────────────────────────────────────────────────────────┘
```

### 2. 关联字段映射

| SaaS端字段 | 酒店端字段 | 说明 |
|-----------|-----------|------|
| `Customer.tenantId` | `Hotel.id` | 租户ID与酒店ID一一对应 |
| `Customer.hotelIds[]` | `Hotel.id` | 支持多酒店集团客户 |
| `HotelData.id` | `Hotel.id` | 酒店唯一标识 |
| `ContentItem.hotelId` | `Hotel.id` | 内容归属酒店 |
| `Ticket.hotelId` | `Hotel.id` | 工单关联酒店 |

### 3. 数据同步机制

#### 实时同步（Webhook）
```typescript
// 酒店端 → SaaS端 事件推送
interface HotelEvent {
  type: 'pricing.updated' | 'inventory.changed' | 'content.published' | 'order.created';
  hotelId: string;
  tenantId: string;
  timestamp: string;
  payload: any;
}
```

#### 定时同步（Cron Job）
- 每5分钟：库存状态同步
- 每小时：交易数据汇总
- 每天凌晨：日结数据同步

### 5. 权限模型

```
SaaS运营后台权限体系：
├── 超级管理员 (super)
│   ├── 所有客户数据
│   ├── 系统配置
│   └── 财务数据
├── 运营管理员 (admin)
│   ├── 客户管理
│   ├── 内容审核
│   └── 数据查看
└── 客服支持 (support)
    ├── 工单处理
    └── 客户咨询

酒店端权限体系：
├── 老板 (owner)
│   ├── 底价修改
│   ├── 模式切换
│   └── 审批权限
├── 经理 (manager)
│   ├── 价格调整
│   └── 库存分配
└── 员工 (staff)
    ├── 内容发布
    └── 订单处理
```

### 6. API 接口设计

```typescript
// 获取酒店详情（SaaS端调用）
GET /api/v1/hotels/:hotelId
Response: {
  hotel: Hotel;
  inventory: Inventory;
  pricing: Pricing;
  platformMetrics: PlatformMetrics[];
}

// 更新库存分配（SaaS端管理）
POST /api/v1/hotels/:hotelId/inventory/allocate
Body: {
  roomTypeId: string;
  platform: Platform;
  allocation: number;
}

// 获取内容列表（双向同步）
GET /api/v1/hotels/:hotelId/contents
Response: {
  contents: ContentItem[];
  stats: {
    total: number;
    approved: number;
    pending: number;
  };
}
```

### 8. 核心业务流程

#### 新客户接入流程
```
1. SaaS端创建 Customer (生成 tenantId)
2. 酒店端初始化 Hotel (使用 tenantId 作为 hotelId)
3. 同步基础数据：房型、库存、底价
4. SaaS端展示酒店运营数据
```

#### 内容投放流程
```
1. 酒店端创建内容 (ContentItem)
2. 推送至SaaS端审核队列
3. SaaS端审核 (AI+人工)
4. 审核通过 → 发布到平台
5. 平台数据回流 → 双方同步
```

#### 库存调拨流程
```
1. 酒店端申请调整灵活池上限
2. SaaS端收到调拨申请（工单）
3. 运营审批 / 自动审批
4. 更新库存分配
5. 同步至酒店端
```
